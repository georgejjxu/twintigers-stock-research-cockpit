# ADR 0001: Java for the research engine

Date: 2026-10-19. Status: accepted.

## Context
The first version is Python (research-tool). The user is an experienced Java engineer and not fluent in Python; they
will maintain and extend this for years, and asked to move to Java.

## Decision
Build the engine in Java, language level 25 (current LTS), compiled with the JDK already installed (26), Maven
multi-module. No application framework: plain constructors (`Wiring`), the MCP Java SDK for the server.

## Consequences
- The user can read, debug and extend every line; standard tooling (IDE, Maven, JUnit).
- Two implementations exist for a while; see ADR 0003 for how that is kept safe.
- Python-only pieces (Kinaxis PDF parsing with pdfplumber, position sizer) stay on the Python server until ported.
- Deviation from the original plan: Temurin 25 was not installed because the existing JDK 26 compiles for 25.
